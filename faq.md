# FAQ

## What is n8n?

[n8n](https://n8n.io) is an open-source workflow automation tool - think Zapier or Make. You drag boxes onto a canvas, connect them with lines, and it runs.

## What is this node?

A community node that adds Sharetribe as a service inside n8n. Once installed, n8n can listen for Sharetribe events (new transaction, new user, booking accepted, etc.) and run actions against your marketplace (approve users, update listings, transition transactions, etc.) without you writing code.

## What can I do with it?

Anything you can do with the Sharetribe Integration API, automated. See the [workflow templates](/templates) for ready-made examples - admin email alerts, booking calendar invites, approving users only after a paid Stripe subscription, syncing new sign-ups to Mailchimp, and more.

## Does it work on n8n Cloud or only self-hosted?

Both. Community nodes are supported on n8n Cloud - see [n8n's installation guide](https://docs.n8n.io/integrations/community-nodes/installation/).

## What does it cost?

The node is free and open source. You'll need a Sharetribe plan that includes Integration API access (Build, Pro, or Extend) and an n8n account (self-hosted or Cloud).

## Is it official?

It's a community-built node, not first-party from Sharetribe or n8n. It's maintained by [TribeBuilder](https://tribebuilder.dev), a verified Sharetribe Expert and verified n8n community node publisher.
