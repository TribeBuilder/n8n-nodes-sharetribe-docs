# Suggest a workflow

Built something useful with the node? Other marketplace operators probably need the same thing.

## Ideas for new workflow templates

Drop them in the [GitHub issue tracker](https://github.com/tribebuilder/n8n-nodes-sharetribe/issues/new) - a few sentences describing what the workflow does is plenty. Include any specific Sharetribe events, transitions, or third-party tools involved.

## Found a bug?

Same place - [open an issue](https://github.com/tribebuilder/n8n-nodes-sharetribe/issues/new). Helpful details to include:

- What you expected to happen vs. what actually happened.
- Your n8n version and Sharetribe plan.
- A screenshot of the n8n Executions view if the error showed up there.

## Need custom work?

[TribeBuilder](https://tribebuilder.dev) - the maintainer - is a verified Sharetribe Expert and takes on paid custom workflows and integrations for marketplaces that want a faster turnaround than the open-source roadmap.

## Want to contribute code?

The repo's on [GitHub](https://github.com/tribebuilder/n8n-nodes-sharetribe). Pull requests welcome. For a new workflow template, drop the JSON under `workflows/public-templates/published/<category>/<slug>.json` - see existing templates for the sticky-note format we use.
